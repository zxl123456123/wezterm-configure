# 快捷键与日常操作

## 启动与加载更新

双击 `D:\terminal-workbench\launchers\01-WezTerm-Only.cmd` 只启动终端工作台；需要顶部栏和平铺时用同目录的 `00-All.cmd`。已有工作台窗口时复用它并补齐缺失标签，不重启正在运行的开发任务。

启动器固定读取 `D:\terminal-workbench\config\wezterm\wezterm.lua`，不是 Git 仓库中的副本。拉取仓库不会自动部署；先备份运行文件并仅替换已验证的对应配置，重载才会加载这次更新。

WezTerm 外观配置默认自动重载；也可按 `Ctrl+Shift+R` 手动重载。默认字号为 11pt；如果此前手动缩放过，按 `Ctrl+0` 恢复配置字号，`Ctrl+-` / `Ctrl++` 临时缩小 / 放大。这些操作不重新启动 Shell。

重新连接 Zellij 仍会保留旧进程，因此 Shell 补全、高亮等源码更新需要新开 Shell，具体命令见下文。Music 缺失或 Player 退出时使用 `D:\terminal-workbench\Restore-Music.cmd`，不必关闭整个会话。

## 标签与面板

下表是当前采用的 Zellij 默认快捷键，不是本仓库自定义按键插件。“然后”表示松开前一组后再按下一键。当前 `config.kdl` 不额外覆写默认键位；若使用不同构建或修改了模式，按你的 Zellij 实际配置核对。

| 需求 | 操作 |
| --- | --- |
| 一键打开整个终端布局 | `launchers\01-WezTerm-Only.cmd` |
| 会话管理器 | `Ctrl+O`，然后 `W`；`Esc` 返回 |
| 切换标签 | `Ctrl+T`，然后 `1` / `2` / `3` / `4` / `5` |
| 新建 / 关闭标签 | `Ctrl+T`，然后 `N` / `X` |
| 移动标签顺序 | `Alt+I` / `Alt+O` |
| 新增 / 关闭面板 | `Alt+N` / `Ctrl+P` 然后 `X` |
| 面板 / 相邻标签导航 | `Alt+方向键` |
| 锁定 / 解锁 Zellij 快捷键 | `Ctrl+G` |
| 真彩图片预览的原生 Yazi 标签 | WezTerm 的 `Ctrl+Shift+I` |

默认标准标签顺序是 Windows Work、Linux Work、Monitor、Music、Control。启动器只在缺失标准标签时插入并调整新标签的位置，不持续重排已有标签，因此手动拖动/移动后的顺序可能不再对应上表的固定数字。

关闭面板/标签会结束其中的程序；先确认没有重要开发命令。恢复布局不等于恢复原来运行的命令。

## Work 与复制粘贴

Windows Work 中输入语法配色由 PSReadLine 提供；已经执行完的任意程序输出不会因此自动获得语法高亮。`ai` 只是按需调用已安装的 `codex` 命令，不是常驻 AI，也没有后台自动补全服务。

本地 PowerShell 5.1 的开发增强（不改变 Linux 远端 Shell）：

| 操作 | 用法 |
| --- | --- |
| 命令 / 参数 / 路径补全 | 输入一部分后按 `Tab`；多项时用方向键选，Enter 确认补全 |
| 按前缀找历史 | 例如先输入 `git`，再按 `↑` / `↓`；空输入时浏览历史 |
| 模糊搜索历史 | `F2` 打开，输入关键字；Enter 只填入命令，再按 Enter 才执行；Esc 取消 |
| 常用目录跳转 | 先正常 `cd` 到目录，提示符出现后学习；以后 `z 关键词`，例如 `z myproject` |
| 挑选目录 | `zi` 或 `zi 关键词`；没有学习过的目录不在列表中 |

F2 只搜索 PSReadLine 已加载的单行历史，不把多行脚本拆成可执行碎片。不要把密码写在命令参数里，历史搜索没有替你脱敏。z/zi 需要可选工具，数据库在 `D:\terminal-workbench\data\zoxide`；不替代原有 cwd 恢复。命令蓝、参数紫、字符串绿、变量粉、错误红，选区使用深色背景与浅色文字。

仅下次自然新开 Work-Windows Shell 才加载更新，重连旧 Zellij 不会刷新现有 Shell。想现在试用时，可在 Work-Windows 用 `Alt+N` 新增面板，再执行下面命令；保留旧面板及任务，不必重启整个窗口：

```powershell
powershell.exe -NoLogo -NoProfile -NoExit -ExecutionPolicy Bypass -File D:\terminal-workbench\Start-WorkShell.ps1
```

远程 Claude Code 等终端程序可能把 `Ctrl+V` 当图片粘贴操作；粘贴文本优先用终端的 `Ctrl+Shift+V`。终端里 `Ctrl+C` 常常是中断进程，不要把它当作通用复制键；选中文本后使用 WezTerm 的 `Ctrl+Shift+C`。不同嵌套程序的鼠标捕获/选择模式会影响是否能直接拖选。

SSH 不会自动把本机图片剪贴板传到远端。需要图片时手动 `scp` 上传，并在远端使用文件路径，不能把“没有剪贴板图片”当作文字复制失败。

## Monitor

鼠标点击表格，或用 Tab 切换聚焦；`J/K`、上下方向键、PageUp/PageDown 滚动。按 `?` 查 bottom 当前版本帮助。默认聚焦进程表，列包含 PID、名称、CPU、内存、读写速率、用户；磁盘表显示挂载、已用、空闲、总量及读写速率。

刷新频率为 1 秒。进程数量多时用表格导航和底部状态，不通过增加几十行文本刷屏。视图行为由 bottom 本身提供，本仓库没有另外实现鼠标滚动特效。

## Music

- 先在歌单中选中歌曲并按 Enter 开始播放；`F7` 上一首、`F8` 暂停/继续、`F9` 下一首。
- 全屏原有 Space / Left / Right 保留；配置弹层优先消费其按键，不让音乐快捷键干扰设置。
- `Q` 退出播放器；恢复使用 `Restore-Music.cmd`。恢复脚本校验 Player 身份与状态，歧义时拒绝操作，不清空其他面板。
- 如果 Music 标签不存在，恢复完整标签布局；如果 Player 已退出，只在原 Player 位置恢复；如果还活着，切换过去。
- 已有 Music 标签缺少 Spectrum 时，脚本不会擅自重建整页。需要完整布局时，先自行确认播放器可退出，再关闭 Music 标签后恢复。

频谱读取默认 Windows 输出设备的所有系统音频；CNMPlayer 暂停后其他应用的声音仍会驱动它。更换默认设备后需以后新开频谱进程。字符深度环绕不是原生 3D；相册 `halfblocks` 是字符半块预览，不是可靠真彩图像协议。

## Control 与背景

使用既有 Control 恢复入口（`D:\terminal-workbench\apps\spectrum-venv\Scripts\python.exe D:\terminal-workbench\apps\control-center\control_center.py control`）：缺少标签时创建原布局；唯一且已退出并保留的 Control，在原位置请求恢复；仍运行时切换过去。恢复只接受配置规定的 Python 控制页或已观察的 GlazeWM 工作区子查询，身份不明、重复或状态变化会拒绝。原位恢复保留其他面板及标签顺序，不重新启动 GlazeWM；离线提示表示窗口管理器尚未运行。恢复请求成功不等于程序已就绪，原退出面板的滚屏会被替换。

GlazeWM 运行时：点击程序卡片聚焦窗口，把程序拖到另一工作区卡片移动。卡片同时标注工作区和显示器；**一个显示器可以对应多个工作区**，不是四个固定显示器，也不是 Windows 虚拟桌面。

`R` 手动刷新。默认 8 秒检查变化；操作后的刷新请求合并；拖动过程中不重建卡片，结束后补刷。GlazeWM 未运行时显示离线提示，不影响使用其他终端标签。

窗口不足 80 列时，顶部背景控件和工作区卡片自动纵排；长程序名与状态文字折行，更多工作区通过原有区域纵向滚动到达。100×30、60×20、40×16 已有隔离布局与操作回归；这些尺寸不表示全部内容同时屏内，24×12 仅作极窄观察。真实鼠标捕获、窗口调度和背景切换仍需下一次自然启动后观察。

Control 顶部图片选择器读取 `D:\terminal-workbench\images`；选择 `none` 用纯色。没有透明度滑条或另外的外观调节页，默认不透出桌面。这里只选择背景，不提供图片缩略图 UI。

浏览器后备页面是手动入口：`python control_center.py open`，监听 `127.0.0.1:8765`。正常 Control 标签不会启动它；这是另一种操作界面，未在本轮做实机视觉验收，也不要对外映射该端口。

## 顶部栏与平铺

YASB 顶部栏显示工作区、媒体、CPU 历史、网络、磁盘和时钟；Search 可搜应用，也支持配置中的 `dev` / `pv` / `ip` 前缀。点击 CPU 查看曲线，点击磁盘展开 C/D/E/G；根据自己的盘符修改配置。

GlazeWM 快捷键：

| 操作 | 快捷键 |
| --- | --- |
| 切换工作区 1–4 | `Ctrl+Alt+1..4` |
| 移动窗口并切过去 | `Ctrl+Alt+Shift+1..4` |
| 聚焦左/下/上/右 | `Ctrl+Alt+H/J/K/L` |
| 平铺/浮动切换 | `Ctrl+Alt+Space` |
| 退出 GlazeWM | `Ctrl+Alt+Shift+E` |

单独启动/停止入口见主 README。停止 GlazeWM 是退出窗口管理器，不是暂停浏览器、微信等程序。

## 减少后台占用

✅ 已实现：开发页无持续粒子动画，AI 辅助按需启动，频谱静音稳定后停止绘制，Control 不因无关焦点变化重建。

频谱复用当前窗口长度的 Hann 数组与当前柱数的频带索引，固定数据构造次数减少，新的音频样本仍逐帧计算 FFT。离线输出等价与构造计数不代表整机 CPU 降幅；音频采集、配色、局部环绕和刷新节奏保持原行为。

⛔ 未实现：按标签是否可见自动暂停音频采集、按 Zellij 标签闲置自动挂起所有后台。

不听歌时可退出 Player；不需要频谱时自行关闭 Spectrum 面板，它的音频采集才会结束。只切到 Work 标签或只关 WezTerm 窗口，不保证 Zellij 的后台任务结束。不需要监控时关 Monitor 标签，以后启动器会补齐；只开发时用终端单独启动入口，并按需停止 YASB / GlazeWM。不要批量杀掉所有 Python 或 SSH 进程。

## 常见问题

- 双击后失败：查看 `data\startup.log`，确认第三方 exe 和默认目录存在；启动器会记录失败阶段及 CLI 原因。
- 文字不高亮：只有 PowerShell 正在输入的语法配色；PSReadLine 不存在或使用 CMD 时，表现不同。
- 图片预览方块：按 `Ctrl+Shift+I` 使用原生 WezTerm Yazi；Zellij 内半块和传输能力不做保证。
- 更新后界面仍旧：当前进程还没加载新源码；不要为了更新打断正在进行的远端任务。
- Control 工作区空：确认 GlazeWM 管理了相关窗口；它不是任务管理器，不能显示所有后台进程。
- 重启后路径恢复失败：核对 cwd 文件和目录是否仍存在；恢复机制没有备份项目文件。
